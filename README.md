# 專案名稱
WealthMap 後端系統（個人財務與資產配置平台 API）

# 專案簡介
本系統為 WealthMap 平台之後端服務，負責提供完整的財務資料處理、資產管理邏輯、投資策略計算與使用者權限控制，並透過 RESTful API 提供前端系統使用。

系統支援多角色架構（訪客 / 使用者 / 管理者），並整合財務分析與投資模擬運算功能。

---

# 系統角色
- 訪客（Guest）
- 使用者（User）
- 管理者（Admin）

---

# 身分驗證與帳號管理
- 使用者登入 / 註冊
- 忘記密碼（發送臨時密碼）
- 登入後強制修改密碼
- JWT 身分驗證（如有實作）
- 權限控管（Role-based Access Control）

---

# 核心功能模組

## 資產管理
- 新增 / 編輯 / 刪除資產
- 新增 / 管理負債
- 資產與負債明細查詢
- 繳款提醒邏輯（負債觸發通知）

---

## 財務目標系統
- 建立財務目標
- 追蹤目標進度
- 與資產數據進行關聯分析（例如購屋目標對應資產累積）

---

## 財務健康分析引擎
計算使用者財務健康分數，包含：
- 負債比
- 理財成就率
- 緊急預備金
- 儲蓄率

並產生分析結果供前端呈現。

---

## 風險評估模組
- 問卷評量設計
- 使用者風險分級
- 推薦投資組合產生邏輯

---

## 投資策略引擎

### 1.資產再平衡
- 依資產比例調整投資組合
- 高點獲利了結（賣高）
- 低點加碼布局（買低）

### 2.加減碼策略
- 根據市場狀況動態調整投入金額
- 上漲減碼、下跌加碼

### 3.投資成長模擬
- 蒙地卡羅模擬（1,000 次以上）
- 模擬不同市場波動情境
- 評估資產成長機率與風險分布
